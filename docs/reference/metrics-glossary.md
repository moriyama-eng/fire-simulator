# Metrics Glossary

Definitions of all metrics, factors, and statistical terms used in the FIRE Monte Carlo Simulator.

## Terminology

| Term | Definition |
|---|---|
| **CB (Cash Buffer)** | A risk-free cash reserve drawn from during a market crash to avoid selling risk assets at a loss. |
| **GR (Guardrail)** | A rule that automatically reduces monthly spending when assets decline below a threshold. |
| **Factor** | A simulation parameter targeted for sensitivity analysis. There are 10 factors (see below). |
| **Level** | The stage of change applied to a factor during analysis. 5 stages: −2, −1, 0, +1, +2. |
| **Base scenario** | The baseline simulation result with no changes applied to any factor. Displayed as "Base Scenario" in the UI; referenced as `baseScenario` in code. |
| **Path** | A single Monte Carlo trial — one complete simulation of all months using a unique sequence of random returns. |
| **Percentile** | The asset level below which a given percentage of paths fall at a given point in time. |

## Simulation Output Metrics

### Success Rate

The fraction of simulation paths (out of `simPaths` total) in which total assets did not reach zero before the end of the simulation period. Expressed as a percentage.

Computed in `js/core/aggregation.js`:
```
successRate = (simPaths - bankruptCount) / simPaths * 100
```

### Final Total Assets

Asset level at the final time step (`dataLen - 1`) for a given percentile. `finalMedian` is the value at the configured median percentile (default: 50th).

### Target Asset Maintenance Rate

Probability that final total assets are at or above `initialTotalAssets × (targetAssetRatio / 100)`.

```
targetThreshold = initialTotalAssets × (targetAssetRatio / 100)
targetAssetMaintainRate = (paths where finalAsset >= targetThreshold) / simPaths × 100
```

Source: `js/core/aggregation.js`, `aggregateResultsProduction`.

### Maximum Drawdown (worst 5% / worst 10%)

Peak-to-trough decline in total assets across the simulation period, expressed as a fraction (negative). `worst10MaxDd` is the 10th-percentile worst value — i.e., 10% of paths had a drawdown worse than this.

Computed via `quickselectSafe` on `maxDdPerPath`:

```
worst5Idx  = floor(0.05 × (simPaths − 1))
worst10Idx = floor(0.10 × (simPaths − 1))
worst5MaxDd  = quickselectSafe(ddCopy, worst5Idx, ...)
worst10MaxDd = quickselectSafe(ddCopy, worst10Idx, ...)
```

Source: `js/core/aggregation.js`, lines 73–79.

### Stagnation Period (Underwater Duration)

Number of consecutive months a path spends with total assets below the initial total assets. Longest such period per path is tracked (`maxUwMonths`).

`medianMaxUw` and `worst10MaxUw` are the median and 90th-percentile worst values across all paths, computed via `quickselectSafe` on `maxUwPerPath`.

### CDF / CCDF Charts

Cumulative and complementary-cumulative distribution functions of per-path statistics (maximum drawdown, stagnation period, etc.).

Generated by `buildCdfPoints` in `js/app/charts.js`:

- **CDF** (`mode='cdf'`): For sorted data index `i`, `P(X ≤ x) = (i + 1) / simPaths × 100`. Last-wins for repeated values.
- **CCDF** (`mode='ccdf'`, default): `P(X ≥ x) = (simPaths − i) / simPaths × 100`. First-wins for repeated values.

## Analysis Factors

The 10 analysis factors are defined in `js/core/factors.js`. Each factor has a `step` (the unit change per level) and a `paramKey` (the simulation parameter it controls).

| Factor Key | Label | Step | Unit | Parameter |
|---|---|---|---|---|
| `initial_risk_asset_jpy` | Initial Risk Assets | 0.1 | 億 (×10⁸ JPY) | `initialRiskAsset` |
| `initial_cash_buffer_jpy` | Initial Cash Buffer | 500 | 万 (×10⁴ JPY) | `initialCashBuffer` |
| `monthly_expense_jpy` | Monthly Expense | 5 | 万 (×10⁴ JPY) | `monthlyExpense` |
| `expected_return_pct` | Expected Return | 1.0 | % | `expectedReturn` |
| `volatility_pct` | Volatility | 1.0 | % | `volatility` |
| `inflation_rate_pct` | Inflation Rate | 0.5 | % | `inflationRate` |
| `drawdown_trigger_pct` | Drawdown Trigger | 5.0 | % | `drawdownTrigger` |
| `replenish_pace_x_expense` | Replenishment Pace | 0.5 | × expense | `replenishPace` |
| `guardrail_trigger_pct` | Guardrail Trigger | 5.0 | % | `guardrailTrigger` |
| `guardrail_reduction_pct` | Guardrail Reduction | 5.0 | % | `guardrailReduction` |

Source: `js/core/factors.js` (10 entries, verified against `tests/unit/analysis-state.test.js` `expect(FACTORS.length).toBe(10)`).

> **Note**: `drawdown_trigger_pct`, `replenish_pace_x_expense` require `cashBufferToggle: true`. `guardrail_trigger_pct`, `guardrail_reduction_pct` require `guardrailToggle: true`.
